FAILURE DEMONSTRATION — Option C: Wrong Port (Transport Layer Failure)

This demonstrates a transport-layer failure by attempting to connect to a
port where no service is listening (port 9999 instead of port 8443).

Affected Layer: Transport (TCP)

The correct nginx HTTPS endpoint runs on port 8443. Port 9999 has no
listener, so the TCP connection is immediately refused by the OS kernel.
No TLS handshake or HTTP exchange occurs.

================================================================================

OUTPUT:

ANALYSIS:
The TCP SYN to port 9999 is immediately rejected with a RST because no
process is listening on that port. The failure occurs at the transport
layer — before any TLS or HTTP exchange can begin.
